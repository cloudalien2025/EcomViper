# EcomViper

Standalone EcomViper application extracted from the broader iBrains monorepo.

## Scope
- EcomViper app shell and pages
- EcomViper API routes
- Shopify connection scaffolding
- Snapshot and BYO key flows

## Quick Start
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
3. Build: `npm run build`

## Required Environment
- `DATABASE_URL`
- `INTEGRATIONS_ENCRYPTION_KEY`
- `SHOPIFY_CLIENT_ID`
- `SHOPIFY_CLIENT_SECRET`
- `APP_BASE_URL`
